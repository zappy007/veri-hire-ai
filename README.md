# VeriHire AI 🛡️

**Developer:** Shashwat Prakash

VeriHire AI is a robust, dual-engine backend API designed to solve two massive bottlenecks in modern HR hiring drives: automated bot spam (Selenium/Puppeteer) and heavily AI-generated applicant content. 

Rather than just wrapping an external AI tool, this project emphasizes backend scalability, algorithmic efficiency, and relational database management.

## ⚙️ Core Architecture & Tech Stack

* **Framework:** Python, FastAPI (Asynchronous processing for heavy I/O tasks)
* **Database:** PostgreSQL (Strictly normalized to 3NF for high-volume storage)
* **Network Security:** Native `INET` IP tracking, cryptographic payload hashing
* **NLP Parsing:** `pdfplumber`, Statistical N-Gram / Perplexity Analysis

## 🚀 The Dual-Engine Approach

### 1. Bot Detection Engine (Security Layer)
Before processing any AI logic, the API filters out high-frequency spam. It utilizes algorithmic rate-limiting, timezone-aware timestamping, and database-level subnet tracking to flag identical origin networks.

### 2. AI Content Detector (NLP Layer)
Extracts raw text from candidate PDFs and applies lightweight statistical NLP metrics (Perplexity and Burstiness) to calculate a confidence score on whether the resume was fully generated by an LLM.

## 🗄️ Database Schema 
The database is structured to decouple heavy AI processing queues from the core application ingestion routing. 
* Uses `UUIDv4` primary keys to prevent endpoint scraping.
* Separated `applications` and `ai_risk_scores` tables for optimized read/write performance.
